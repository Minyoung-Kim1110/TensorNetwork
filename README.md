# TensorNetwork

Tensor-network code for **quantum computing simulation** and **condensed-matter calculations**.  
This repository is centered around a small Python `src/` codebase plus a set of Jupyter notebooks (e.g. Heisenberg triangle, non-interacting tight-binding chain, SIAM/NRG exercises). :contentReference[oaicite:0]{index=0}

- `Non-InteractingTightBindingChain.ipynb` — example: free-fermion tight-binding chain :contentReference[oaicite:4]{index=4}  
- `SIAM_NRG.ipynb` — example: SIAM / NRG-style workflow notebook :contentReference[oaicite:5]{index=5}
